# Image Studio

日本語で使えるローカルGPU向け写真編集アプリ。証明写真の背景変更・トリミング・印刷を、3つのタブで使えます。

- 背景: BiRefNet HR-matting、任意のViTMatte補正、rembgによる前景色推定・合成。色テンプレートとカラーパレット。
- トリミング: 証明写真の用途別サイズ、顔の自動配置、手動調整。300dpi PNGを保存。
- 印刷: A4、L判、2L判、はがき。実寸を保ったPNGとPDF。

美顔・肌色補正・ウォーターマーク・サンプル画像はありません。

## 起動

ROCm 7.2対応AMD GPUが必要です。コンテナイメージは `ghcr.io/otama-homelab/image-studio:1.0.1`。ポート7860、非root UID/GID 1000で実行します。GPUデバイスへのアクセスと書き込み可能な `/cache` を設定してください。モデルは初回起動時に公式配布元から取得し、キャッシュを再利用します。依存・コードはイメージ内にあり、venvや起動時のpipインストールは不要です。

写真は一時領域で処理し、出力は1時間後に削除します。外部推論APIへの送信はありません。インターネットへ公開する場合は別途認証を設定してください。

## リリース

GitHub Actionsの「Bump version」でpatch/minor/majorを選択すると、`VERSION` を更新し、対応する `vX.Y.Z` タグを作成してリリースworkflowを呼び出します。タグを手動pushしてもビルドできます。SemVerのイメージタグとdigestをGitHub Releaseに記録します。公開済みタグは変更しません。

新しい画像処理は `app/image_studio_app.py` の `tools` に親タブを追加します。GPUキューは直列で共有します。

## モデル

モデルのリビジョン・SHA256は `app/prepare_models.py` に固定しています。InsightFaceの学習済みモデルは非商用研究用途の条件です。モデルはイメージへ同梱しません。

米国パスポート提出用は白／オフホワイト背景で撮影した元写真をトリミングしてください。デジタル背景変更は使わず、印刷後の実寸と頭の高さを確認してください。
