# 写真の編集と印刷

[アプリを開く](https://image-studio.otama-playground.com/)。必要な工程へ直接入れます。背景編集を行わず、サイズ調整や印刷だけ使うこともできます。

1. **背景編集**：写真・モデル・CPU/GPU・背景色・輪郭補正を選び、処理を開始します。中央線をドラッグ、または左右キーで比較し、PNGを保存します。初回はモデル取得が必要です。
2. **サイズ調整**：用途または寸法を選び、位置と写る範囲を調整してPNGを作成・保存します。画像上のドラッグで移動、ホイールやピンチでズームできます。
3. **印刷**：サイズ調整済みの画像を渡すか、別の写真を直接選び、用紙とPNG/PDFを指定して保存します。実寸印刷は100%・実際のサイズを選び、用紙への自動拡大縮小を避けてください。

右上で日本語・英語を切り替えられます。言語の選択だけを端末へ保存します。写真・設定・生成ファイルはメモリ内にあり、再読み込みやページを離れると失われます。必要なファイルを先に保存してください。

写真は外部推論APIへ送信しません。モデルは端末へ取得して処理します。PCの高画質CPUは非常に遅く、RAMも多く必要です。スマホではHRモデルを提供しません。
