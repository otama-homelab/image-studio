# 写真の編集と印刷

[ドキュメント一覧](../README.md#ドキュメント)

## 基本の流れ

1. 「背景変更」で写真と背景色を選び、「背景を変更」を押します。
2. プレビューの比較バーを左右に動かし、髪・輪郭・肩の仕上がりを確認します。矢印キーでも操作できます。
3. 「この画像をトリミングへ →」でサイズと顔の位置を整え、「このサイズで保存」を押します。
4. 「この写真を印刷へ →」で用紙を選び、印刷レイアウトのPNGまたはPDFを保存します。

各タブに直接写真をアップロードすることもできます。背景を変える必要がない写真は、トリミングから始めてください。保存ボタンは処理結果ができた後に表示されます。

## 背景変更

白・オフホワイト・青・グレーのスウォッチ、またはカラーパレットから色を選びます。アップロードは20MBまで、背景処理は長辺2000pxまでです。大きな入力画像は縮小されますが、画角は維持します。

「切り抜きの詳細設定」の「髪・輪郭を精密に補正」は標準ONです。輪郭が欠けたり、服の境界が不自然になったりする場合は、OFFにして比較してください。どの写真でもONの方が良くなるとは限りません。

- **背景付きPNG:** 選んだ色を合成した画像です。
- **透過PNG:** 背景が透明なRGBA画像です。
- **そのまま印刷へ:** トリミングせずに印刷タブへ渡します。写真の大きさはピクセル数から300dpiとして計算するため、証明写真の寸法を決める用途では先にトリミングしてください。

写真・色・補正設定を変更すると、古い結果と保存ボタンを消します。タブを往復しても結果は維持します。

## トリミング

| プリセット | 幅×高さ |
|---|---|
| 履歴書・在留カード | 30×40mm |
| パスポート・マイナンバー | 35×45mm |
| 運転免許 | 24×30mm |
| 米国パスポート | 50.8×50.8mm（2×2インチ） |
| カスタムサイズ | 幅・高さをそれぞれ9〜152mmで指定 |

プリセットは寸法の設定です。提出先ごとの最新要件や写真の適合を自動判定するものではありません。

「顔を中央に合わせる」で初期位置を求め、画角・横位置・縦位置を手動で調整します。頭頂は人物マスクから推定するため、髪型や背景によって誤差があります。プレビューと印刷後の実寸を確認してください。自動回転・顔の変形・肌色補正は行いません。

保存した写真は300dpiのPNGです。例として30×40mmは354×472px、2×2インチは600×600pxになります。設定を変更したら、もう一度保存してから印刷タブへ渡してください。

## 印刷

| 用紙 | 幅×高さ |
|---|---|
| A4 | 210×297mm |
| L判 | 127×89mm |
| 2L判 | 178×127mm |
| はがき | 100×148mm |

写真のピクセル寸法を300dpiの実寸として配置します。用紙の余白は約5mm、写真の間隔は約3mmです。収まる枚数を自動で並べ、PNGとPDFを出力します。

PDFなどを印刷するときは、**100%／実際のサイズ**を選び、「用紙に合わせる」を無効にしてください。用紙・プリンター設定を合わせ、最初の1枚は定規で寸法を確認します。写真として提出する場合は、提出先が指定する写真用紙を使用してください。

直接アップロードした写真にDPI情報がない場合は300dpiとして扱います。300dpi以外の情報がある画像はエラーになるので、トリミングタブで300dpiとして保存し直してください。

## 写真の保存期間

入力・出力はサーバーの一時領域に置きます。出力とGradioキャッシュは1時間を過ぎると5分間隔で削除され、コンテナを作り直した場合も消えます。残したい写真は手元へダウンロードしてください。モデル用キャッシュには写真を保存しません。
