# トラブルシューティング

- **背景処理が失敗する**：エラーの段階・コードを確認し、モデル取得時は接続・空き容量を確認します。端末情報は画面から確認でき、診断JSONは明示保存できます。写真を選び直す前に再試行してください。
- **PCでGPUを使えない**：対応ブラウザとGPU設定を確認します。CPUは明示選択できますが、高画質は非常に遅くなります。スマホではHRを表示しません。
- **モデル取得が進まない**：接続とブラウザの保存容量を確認します。必要に応じてアプリのモデル管理から削除・再取得します。ページ再読み込みでは写真が失われるため、保存可能なものは先に保存してください。
- **印刷寸法が変わる**：PDFを100%・実際のサイズで印刷し、fit・フチなし拡大・用紙への自動拡大縮小を確認します。
- **再読み込みで写真が消えた**：写真はメモリ内保持です。ブラウザを閉じる・再読み込みする前にPNG/PDFを保存してください。

開発者向けの配信失敗・復帰は[リリース手順](releases.md)を参照してください。旧サーバーのROCm、Gradio、Docker、ポート7860の設定は現行アプリには不要です。
