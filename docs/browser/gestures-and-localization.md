# Preview gestures and Japanese / English

The comparison divider uses react-compare-slider 4.0.0 (MIT) with direct dragging and arrow-key controls. Original/result buttons were removed after user feedback. The external range and comparison zoom/pan controls were removed after user feedback: wheel and vertical touch gestures should scroll the page. No wheel handler or inner scroll container is used. Comparison reuses existing image URLs without inference, encoding or saved-dimension changes. The unused react-zoom-pan-pinch dependency was removed.

Resize uses react-easy-crop 6.2.4. Its drag, wheel and pinch operations change the actual crop and update the numeric controls. Wheel sensitivity is fixed at zoomSpeed 0.1 for finer adjustment; the range control remains available for larger changes. onWheelRequest marks the first wheel edit before the library emits crop coordinates. Active interaction sources are tracked separately so wheel cleanup cannot end an ongoing mouse/touch drag. Every edit retains the existing output invalidation and source-ownership checks.

Localization uses i18next 26.7.1 and react-i18next 17.1.12 (MIT). English is the default; existing saved Japanese preferences are retained; the header selects Japanese or English and stores only that preference. Each view subscribes without remounting editor sessions. Dictionaries include UI text, accessible names, errors, consent, resource estimates and shipped model descriptions. HTML lang/title/description follow the selection. Existing formatted session notices are resolved at the presentation boundary, including previously stored notices, to preserve photos, settings and error details during language changes. No translation API or new server is used. Original dependency/model license documents are unchanged.

Checks: all 345 web tests, TypeScript, 26 build/distribution tests and the model-enabled static build passed. Regression tests cover first-wheel synchronization, overlapping gestures, divider drag/keyboard and absent redundant buttons and native wheel scrolling, dictionary key/parameter parity, denied preference storage and language changes with a held photo. Local Chromium exercised divider dragging, native page scrolling over comparisons, and crop zoom/pan adjustments using the licensed synthetic example, with language switching retaining the photo and values. Phone-width rendering was checked; real-device pinch gestures remain unverified. No model inference was run.
